# Virtual Laboratory - Hooke's Law Milestone

Interactive Three.js Hooke's Law practical.

## Interaction
1. Select Hooke's Law.
2. Click **Get 100 g mass**.
3. Drag the mass from the bench toward the spring.
4. Drop it near the spring to attach it.
5. Add more masses and observe the spring extension.
6. Use **Remove** or **Reset experiment**.

The prototype calculates `F = kx` using a fixed spring constant of 19.6 N/m and gravitational acceleration of 9.81 m/s².

The spring response is driven by the experiment model rather than a rigid-body physics engine.
